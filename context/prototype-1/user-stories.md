# User stories (v1 + v2 combined)

## Less experienced fresh-department employee

1. As a fresh-department employee, I want to see all promotional displays in the department, sorted by how urgently they need attention, so that I know what to handle first.
2. As a fresh-department employee, I want to select a display and see its planned product and current fill, so that I understand the situation before I act.
3. As a fresh-department employee, I want to see the top 5 substitutes for an empty display, each with a short reason, so that I can choose quickly and explain my choice.
4. As a fresh-department employee, I want to correct the stock amount of a product, so that the suggestions match what is really in storage.
5. As a fresh-department employee, I want to get a warning when a product shouldn't be placed next to another one, so that I avoid a wrong display decision.
6. As a fresh-department employee, I want to see how much of a product fits on the display, so that I don't overfill it.
7. As a fresh-department employee, I want to see the manager's focus for today, so that I know what the manager on duty expects.
8. As a fresh-department employee, I want to have my decision logged with its reasons, so that the manager can see why I made it and I don't have to fear their reaction.

## Department manager

9. As a department manager, I want to set the priority of the day (presentation, availability or waste), so that the suggestions follow my standards.
10. As a department manager, I want to leave notes for employees on specific dates, so that they are informed without me having to be there.
11. As a department manager, I want to create tasks for future dates, so that specific work gets done on specific occasions.
12. As a department manager, I want to review the decision log of a shift, so that I can give feedback and know which employees I can trust with decisions.
13. As a department manager, I want to agree on shared placement rules with other managers, so that employees don't face different standards.
