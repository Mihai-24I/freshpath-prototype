# Prototype 2 – User test scenarios

Nov 6, 2026 · @Mihai

Six tasks, run in this order without resetting the demo data in between. Five task names match prototype 1 so the scores can be compared; task 2 no longer says "top 5" because display C shows 4 available alternatives.

| Task | Scenario |
| --- | --- |
| Find a display that needs attention. | You are a fresh department employee at a supermarket in your city. You just started your afternoon shift. Find out which promotional display needs refilling right away. |
| Find the alternatives for a product. | During your shift you noticed that avocados started running low, still not empty, but low. Find the display and check which products could replace them. |
| Choose the best alternative and find out why it is so. | Find the best alternative. Right after doing that, one of the shift leaders sees you removing avocados from their display area and asks you why this is a better decision. Find that information in the app and explain it in your own words. |
| Complete a refilling action until the end. | You are ready to refill the display with the new product. Your shift leader doesn't want it completely full: place 10 pieces, then make sure the app has saved your refill. |
| Change a product yourself. | Display H is empty. The manager tells you to put blueberries there. There is no need for suggestions, change it yourself and check whether it's a good fit. |
| Prevent food waste. | It is the end of your shift. Check storage for a product that has to be sold soon and put it on a promo display that needs it. |

## Setup

- Log in as Mia (`mia@freshpath.demo` / `demo1234`) before the test starts; the tester begins on the Overview.
- Before each new tester: Profile → Reset demo data, then log in as Mia again. Decide once whether testers see the first-use intro, and keep it the same for everyone.
- Score each task like prototype 1: 3 = can do the task quickly and without trouble · 2 = can do the task but has some struggles (or the interviewer helped) · 1 = can't perform the task.
